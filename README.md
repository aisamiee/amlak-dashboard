# داشبورد مزایدهٔ املاک رضوی

پایش و ارزش‌گذاری مزایده‌های هفتگی زمین آستان قدس رضوی ([amlak.razavi.ir](https://amlak.razavi.ir/panel/auctions)) در مشهد و حومه، با تمرکز بر کاربری مسکونی و مدل مشارکت در ساخت.

**نسخهٔ آنلاین:** https://aisamiee.github.io/amlak-dashboard/
دادهٔ این نسخه رمزگذاری شده است و فقط با رمز باز می‌شود.

## چه چیزی دارد
- **نمای کلی:** وضعیت مرحلهٔ جاری، بهترین فرصت‌ها، و تحولات نسبت به مرحلهٔ قبل (قطعه‌های تازه، تغییر قیمت، فروخته‌ها با قیمت متری).
- **فرصت‌های فعال:** جدول قابل فیلتر قطعه‌های در حال عرضه.
- **نقشه:** موقعیت هر قطعه از «مختصات مرکز ملک» چاپ‌شده روی کروکی (UTM منطقهٔ ۴۰).
- **پروندهٔ قطعه:** کروکی، تاریخچهٔ قیمت در همهٔ مراحل، برنامهٔ ساخت، مدل مشارکت و سناریوها.
- **ماشین‌حساب مشارکت:** همهٔ فرض‌ها قابل تغییرند و نتیجه همان لحظه حساب می‌شود.
- **بازار و محله‌ها، بایگانی، پیگیری شخصی، روش و منابع.**

## اجرا روی مک
روی `start.command` دوبار کلیک کنید. سرور محلی روی `http://127.0.0.1:8765/` بالا می‌آید.
این نسخه دادهٔ کامل و یادداشت‌های شخصی را از پوشهٔ پروژه می‌خواند.

## به‌روزرسانی
سایت مزایده فقط از IP ایران و با مرورگر واقعی باز می‌شود، پس جمع‌آوری داده روی مک انجام می‌شود:

```
scripts/update.sh      # دریافت مراحل تازه، ارزش‌گذاری، مختصات کروکی، ساخت داده‌های داشبورد
scripts/publish.sh     # رمزگذاری داده در docs/ و انتشار روی GitHub Pages
```

## ساختار
| مسیر | کار |
|---|---|
| `scripts/scrape.js` | دریافت صفحه‌های هر مرحله با Playwright |
| `scripts/parse.py`، `track.py` | استخراج آگهی‌ها و ردیابی هر قطعه بین مراحل |
| `scripts/valuation.py`، `market.py` | برنامهٔ ساخت، مدل مشارکت، سقف پیشنهاد |
| `scripts/kroki_coords.py`، `geo.py` | خواندن مختصات UTM از کروکی‌ها (Apple Vision + طبقه‌بند ارقام فارسی) |
| `scripts/build_app.py` | ساخت `app/data.json`، تصاویر کوچک و snapshot تغییرات |
| `scripts/build_site.py` | نسخهٔ رمزگذاری‌شده برای `docs/` (AES-256-GCM، کلید از رمز با PBKDF2) |
| `app/` | داشبورد (HTML/CSS/JS بدون فریم‌ورک، Leaflet برای نقشه) |
| `docs/` | نسخهٔ منتشرشده روی GitHub Pages |

دادهٔ خام، ارزش‌گذاری‌ها، رمز سایت و یادداشت‌های شخصی در مخزن نیستند (`.gitignore`).
